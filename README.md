# 📚 Learning Vocabulary

An interactive English vocabulary learning website designed to help learners understand and improve their English vocabulary in an easy and engaging way.

## 🌐 Live Website

🔗 **Live Demo:** https://learning-vocabulay-platform.vercel.app

---

## ✨ Features

- 📖 Learn English words with their meanings
- 🔊 Listen to the correct pronunciation of words
- 🔍 Search for specific words and their meanings
- 📚 View detailed information about each word
- 🔄 Explore synonyms of words
- 💡 Understand words through practical examples
- 🎯 Browse vocabulary lessons by level
- 📱 Responsive and user-friendly interface

---

## 🧠 What You Can Learn

For each vocabulary word, you can explore:

- **Word**
- **Meaning**
- **Pronunciation**
- **Synonyms**
- **Example sentence**
- **Detailed word information**

This helps learners understand not only the meaning of a word but also how it can be used in real situations.
